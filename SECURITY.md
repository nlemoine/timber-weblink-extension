# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | Yes                |
| < 2.0   | No                 |

## Reporting a vulnerability

Do not report vulnerabilities in public issues, pull requests or discussions.

Use GitHub private vulnerability reporting instead: open the [Security tab](https://github.com/nlemoine/timber-weblink-extension/security) of the repository and choose "Report a vulnerability", or go directly to https://github.com/nlemoine/timber-weblink-extension/security/advisories/new.

Please include:

- the affected version of Timber WebLink Extension, Timber, WordPress and PHP;
- a description of the vulnerability and its impact;
- steps to reproduce it, ideally with a minimal proof of concept.

You can expect an acknowledgement of your report, and a fix and coordinated disclosure once the issue is confirmed.
